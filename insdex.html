📊 Python Visualization Library

Make beautiful
statistical charts
with ease

Seaborn is built on top of Matplotlib and integrates deeply with pandas DataFrames — making complex statistical graphics simple and elegant.

Get Started → Cheat Sheet
🎨

Beautiful by default

Comes with carefully crafted default themes that make statistical plots look professional with zero effort.

🐼

Pandas-native

Pass a DataFrame directly. Seaborn understands column names, automatically labels axes, and handles grouping.

📈

Statistical built-in

Bootstrap confidence intervals, kernel density estimates, regression fits — built right into the plotting functions.

⚡

One-line plots

Complex visualizations like pair plots, heatmaps, and facet grids require just a single function call.

🔧

Matplotlib compatible

Every seaborn figure is a Matplotlib object — use plt functions for fine-tuned control whenever needed.

🎲

Built-in datasets

Load classic datasets instantly with sns.load_dataset() for practice and experimentation.

💡

New to Python visualization? Seaborn is the best starting point — it hides Matplotlib's complexity while still giving you full access when you need it. Start with the Quick Start section.

Install with pip

The easiest way to install seaborn is using pip, Python's package manager:

terminal 
$ pip install seaborn

Install with conda

If you use Anaconda or Miniconda:

terminal 
$ conda install seaborn

Verify your installation

python 
import seaborn as sns

2 Quick Start

Go from zero to your first plot in 5 minutes.

The standard imports

Every seaborn script starts with these lines:

python 
import seaborn as sns          # seaborn aliased as sns
import matplotlib.pyplot as plt  # matplotlib for showing/saving
import pandas as pd             # for DataFrames
import numpy as np              # for numeric data

Your first plot in 3 lines

python 
tips = sns.load_dataset("tips")       # 1. Load sample data
sns.scatterplot(data=tips, x="total_bill", y="tip")  # 2. Plot
plt.show()                                     # 3. Display
sns.scatterplot(data=tips, x="total_bill", y="tip")

The workflow pattern

1

Load or create data

Use sns.load_dataset() for built-in datasets, or bring your own pandas DataFrame.

2

Choose a plot function

Pick from scatter, line, bar, hist, box, violin, heatmap, and more.

3

Map columns to aesthetics

Use x=, y=, hue=, size=, style= to encode data visually.

4

Display or save

Call plt.show() to display or plt.savefig("plot.png") to save.

Adding hue — grouping by color

python 
tips = sns.load_dataset("tips")

sns.scatterplot(
    data=tips,
    x="total_bill",
    y="tip",
    hue="time",    # Color by "Lunch" or "Dinner"
    size="size",   # Dot size = party size
    style="sex"    # Marker shape by gender
)
plt.title("Tips Dataset")
plt.show()

4 Themes & Styles

Control the look and feel of every plot globally.

Setting a theme

python 
# Set a theme for all subsequent plots
sns.set_theme()                     # default seaborn theme
sns.set_theme(style="darkgrid")    # dark background + grid
sns.set_theme(style="whitegrid")   # white bg + grid
sns.set_theme(style="dark")        # dark, no grid
sns.set_theme(style="white")       # white, no grid
sns.set_theme(style="ticks")       # white + axis ticks

Controlling context (scale)

The context parameter adjusts font size and line widths for different output destinations:

python 
sns.set_context("paper")    # smallest — for papers/journals
sns.set_context("notebook")  # default — for Jupyter notebooks
sns.set_context("talk")     # larger — for presentations
sns.set_context("poster")   # largest — for posters

# Fine control with font_scale
sns.set_context("notebook", font_scale=1.5)

Temporarily changing style

python 
# Only affects plots inside the with block
with sns.axes_style("whitegrid"):
    sns.histplot(data=tips, x="total_bill")
    plt.show()

5 Color Palettes

Color is one of the most powerful visual encodings — seaborn makes it beautiful by default.

python 
# Set palette globally
sns.set_palette("deep")

# Use palette in a single plot
sns.barplot(data=tips, x="day", y="tip", palette="viridis")

# View a palette
sns.palplot(sns.color_palette("Set2"))
plt.show()

Qualitative palettes (categorical data)

deep

Blues

Rule of thumb: use qualitative for categories, sequential for amounts, and diverging for values that go positive and negative around a center.

6 Relational Plots

Show relationships between two or more numeric variables.

scatterplot()

The most common relational plot. Each point represents one observation.

python 
tips = sns.load_dataset("tips")

# Basic scatter
sns.scatterplot(data=tips, x="total_bill", y="tip")

# With grouping
sns.scatterplot(
    data=tips,
    x="total_bill", y="tip",
    hue="smoker",   # color by group
    style="time",   # marker shape
    size="size",    # point size
    alpha=0.7       # transparency
)
plt.show()

lineplot()

Connects points in order of the x variable. Perfect for time series. Automatically draws confidence intervals.

python 
flights = sns.load_dataset("flights")

# Line plot with confidence interval (aggregates by year)
sns.lineplot(data=flights, x="year", y="passengers")

# Split into multiple lines by month
sns.lineplot(
    data=flights,
    x="year", y="passengers",
    hue="month"
)
plt.show()

relplot() — figure-level interface

relplot() wraps both scatter and line plots into a figure-level interface with automatic facetting:

python 
# Creates subplots automatically using col=
sns.relplot(
    data=tips,
    x="total_bill", y="tip",
    col="time",      # one column per "time" value
    hue="smoker",
    kind="scatter"  # or "line"
)
plt.show()

7 Distribution Plots

Visualize how data is spread — essential for EDA (exploratory data analysis).

histplot()

python 
# Basic histogram
sns.histplot(data=tips, x="total_bill")

# Histogram + KDE curve (density overlay)
sns.histplot(data=tips, x="total_bill", kde=True)

# Grouped histograms
sns.histplot(
    data=tips, x="total_bill",
    hue="sex",
    bins=20,          # number of bins
    multiple="stack"  # "layer", "dodge", "fill", "stack"
)
plt.show()

kdeplot() — Kernel Density Estimate

Smooth probability density curve. More informative than a histogram for continuous data.

python 
# 1D KDE
sns.kdeplot(data=tips, x="total_bill")

# 2D KDE (bivariate)
sns.kdeplot(
    data=tips, x="total_bill", y="tip",
    fill=True,     # fill contours
    thresh=0.05,  # cut off lowest density
    levels=10     # number of contour levels
)
plt.show()

ecdfplot() — Cumulative Distribution

python 
sns.ecdfplot(data=tips, x="total_bill", hue="sex")
plt.show()

displot() — figure-level wrapper

python 
# Faceted histograms
sns.displot(
    data=tips, x="total_bill",
    col="time",
    kind="kde"  # "hist", "kde", "ecdf"
)
plt.show()

8 Categorical Plots

Show distributions or comparisons across categorical groups.

barplot()

Shows mean (or another estimator) with a confidence interval bar.

python 
# Average tip per day
sns.barplot(data=tips, x="day", y="tip")

# Grouped by sex, order bars
sns.barplot(
    data=tips, x="day", y="tip",
    hue="sex",
    order=["Thur", "Fri", "Sat", "Sun"],
    estimator="median"  # default is "mean"
)
plt.show()

boxplot()

Shows median, quartiles, and outliers. Great for comparing distributions.

python 
sns.boxplot(data=tips, x="day", y="total_bill", hue="smoker")
plt.show()

violinplot()

Like a box plot but shows the full distribution shape using KDE.

python 
sns.violinplot(
    data=tips, x="day", y="total_bill",
    hue="sex",
    split=True  # show each hue on different side
)
plt.show()

stripplot() & swarmplot()

Show individual data points. swarmplot avoids overlapping by spreading points.

python 
# Strip plot (random jitter)
sns.stripplot(data=tips, x="day", y="tip", jitter=True)

# Swarm plot (beeswarm — no overlapping)
sns.swarmplot(data=tips, x="day", y="tip", hue="sex")
plt.show()

countplot()

Counts the number of observations in each category:

python 
titanic = sns.load_dataset("titanic")
sns.countplot(data=titanic, x="class", hue="survived")
plt.show()
FunctionShowsUse When
barplot()Mean + CIComparing averages
boxplot()Median, IQR, outliersQuick distribution comparison
violinplot()Full distribution shapeUnderstanding distribution shape
stripplot()Individual pointsSmall datasets (< 200 rows)
swarmplot()Points, no overlapSmall-medium datasets
countplot()Category countsFrequency of categories
pointplot()Mean + CI with linesTrends across categories

9 Regression Plots

Visualize linear (and non-linear) relationships with confidence intervals.

regplot()

Scatter plot with a fitted regression line + confidence band.

python 
# Linear regression line
sns.regplot(data=tips, x="total_bill", y="tip")

# Polynomial regression (order=2 is quadratic)
sns.regplot(
    data=tips, x="total_bill", y="tip",
    order=2,        # polynomial degree
    ci=95,          # confidence interval %
    scatter_kws={"alpha": 0.4}
)
plt.show()

lmplot() — faceted regression

python 
# Regression split by groups
sns.lmplot(
    data=tips,
    x="total_bill", y="tip",
    hue="smoker",  # different line per group
    col="time"     # separate subplots by time
)
plt.show()

residplot()

Check if residuals are randomly distributed (validates linear regression assumptions):

python 
sns.residplot(data=tips, x="total_bill", y="tip")
plt.show()
⚠️

regplot vs lmplot: Use regplot() when you want to add regression to an existing axes. Use lmplot() when you want faceting (separate subplots by category) — it creates its own figure.

10 Matrix Plots

Visualize 2D arrays — correlation matrices, pivot tables, and more.

heatmap()

The classic visualization for correlation matrices:

python 
# Correlation heatmap
corr = tips.select_dtypes("number").corr()

sns.heatmap(
    corr,
    annot=True,    # show numbers in cells
    fmt=".2f",     # 2 decimal places
    cmap="RdBu_r", # diverging colormap
    center=0,      # center colormap at 0
    vmin=-1, vmax=1
)
plt.show()

# Pivot table heatmap (flights dataset)
flights = sns.load_dataset("flights")
pivot = flights.pivot(index="month", columns="year", values="passengers")
sns.heatmap(pivot, annot=True, fmt="d", cmap="YlOrRd")
plt.show()

clustermap()

Hierarchically-clustered heatmap — reorders rows and columns by similarity:

python 
iris = sns.load_dataset("iris")
iris_num = iris.drop("species", axis=1)

sns.clustermap(
    iris_num,
    cmap="vlag",
    standard_scale=1  # normalize each column
)
plt.show()

11 Multi-Plot Grids

Build complex multi-panel figures with minimal code.

pairplot()

Visualizes all pairwise relationships in a dataset at once:

python 
iris = sns.load_dataset("iris")

# Basic pairplot
sns.pairplot(iris, hue="species")

# Custom diagonal (KDE instead of histogram)
sns.pairplot(
    iris,
    hue="species",
    diag_kind="kde",
    plot_kws={"alpha": 0.6}
)
plt.show()

FacetGrid

The most flexible way to build subplot grids. Separate any plot by rows and/or columns of categories:

python 
# Create grid: 1 column per "time", 1 row per "sex"
g = sns.FacetGrid(tips, col="time", row="sex", height=4)

# Map any plotting function onto it
g.map_dataframe(sns.histplot, x="total_bill")
g.add_legend()
plt.show()

JointGrid — joint + marginal plots

python 
# jointplot = one-liner shortcut
sns.jointplot(
    data=tips,
    x="total_bill", y="tip",
    kind="reg"  # "scatter", "kde", "hex", "hist", "reg", "resid"
)
plt.show()

12 Customization

Seaborn plots are Matplotlib objects — customize anything.

Titles, labels & size

python 
fig, ax = plt.subplots(figsize=(10, 6))  # width, height in inches

sns.barplot(data=tips, x="day", y="tip", ax=ax)

# Customize via Matplotlib
ax.set_title("Average Tips by Day", fontsize=16, fontweight="bold")
ax.set_xlabel("Day of Week")
ax.set_ylabel("Average Tip ($)")
ax.set_xticklabels(ax.get_xticklabels(), rotation=45)
ax.spines["top"].set_visible(False)
ax.spines["right"].set_visible(False)
plt.tight_layout()
plt.show()

Saving figures

python 
plt.savefig(
    "my_plot.png",
    dpi=300,         # high resolution for print
    bbox_inches="tight",  # removes extra whitespace
    transparent=True  # transparent background
)

# Also supports .svg, .pdf, .jpg
plt.savefig("chart.svg")

Combining violin + strip plot

Layer multiple seaborn plots on the same axes:

python 
fig, ax = plt.subplots(figsize=(8, 5))

# Draw violin first
sns.violinplot(
    data=tips, x="day", y="tip",
    inner=None, color=".8", ax=ax
)
# Overlay individual data points
sns.stripplot(
    data=tips, x="day", y="tip",
    jitter=True, size=3, alpha=0.5, ax=ax
)
plt.show()

13 Objects Interface New in v0.12

A composable, declarative system for building plots — the future of seaborn.

🆕

The objects interface was introduced in seaborn 0.12 and offers a fundamentally different, more flexible way to create plots by chaining operations together.

Basic structure

python 
import seaborn.objects as so

(
    so.Plot(tips, x="total_bill", y="tip")
    .add(so.Dot())                 # scatter dots
    .show()
)

Composing marks & transforms

python 
import seaborn.objects as so

(
    so.Plot(tips, x="total_bill", y="tip", color="smoker")
    .add(so.Dot(alpha=0.5))          # raw points
    .add(so.Line(), so.PolyFit())    # regression line
    .label(title="Tips with Fit")
    .show()
)

Available Marks

MarkWhat it draws
so.Dot()Scatter points
so.Line()Connected line
so.Bar()Bars
so.Area()Filled area
so.Path()Custom path marks
so.Text()Text annotations
so.Range()Error bars / ranges
